# Endpoints de Ingesta de Cotizaciones - Diseño Multi-Canal

## Descripción General

Este documento define los **endpoints de ingesta** para recibir solicitudes de cotización desde múltiples canales:

1. 📝 **Entrada Manual** - Operador interno ingresa datos vía UI
2. 💬 **WhatsApp** - Cliente envía mensaje (texto/audio) → Webhook
3. 🌐 **Formulario Web Público** - Cliente llena formulario en sitio web
4. 🤖 **Asistido por IA** - Agente IA extrae datos desde mensajes/archivos

## 2️⃣ Endpoint: WhatsApp Webhook

### Descripción

Cliente envía mensaje por WhatsApp (texto o audio). El webhook recibe el mensaje, la IA extrae los datos y crea un borrador de cotización.

### Flujo

1. Cliente escribe: *"Necesito 50 M3 de calicote para Villa Bernardo"*
2. WhatsApp API envía webhook → Quotation Service
3. IA extrae: `{ item: "calicote", quantity: 50, unit: "M3", location: "Villa Bernardo" }`
4. Se crea borrador de cotización
5. Sistema responde por WhatsApp: *"✅ Recibido. Cotización #1507 en revisión. Te contactamos pronto."*
